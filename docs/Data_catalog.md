# Data Dictionary - Gold Layer

## Overview

The Gold Layer contains a business-ready dimensional model implemented using a Star Schema. It provides curated and analytics-ready data for reporting, dashboarding, and business intelligence use cases.

---

# gold.dim_customers

## Purpose

Provides a consolidated customer dimension by combining customer information from CRM and ERP systems. This table is used for customer analytics, segmentation, demographic analysis, and sales reporting.

## Source Tables

- `silver.crm_cust_info`
- `silver.erp_cust_az12`
- `silver.erp_loc_a101`

## Columns

| Column Name | Data Type | Description |
|------------|-----------|-------------|
| customer_key | BIGINT | Surrogate key generated for each customer record |
| customer_id | INT | Unique customer identifier from CRM |
| customer_number | NVARCHAR(50) | Customer business key used across source systems |
| first_name | NVARCHAR(50) | Customer first name |
| last_name | NVARCHAR(50) | Customer last name |
| country | NVARCHAR(50) | Customer country from ERP location data |
| marital_status | NVARCHAR(50) | Standardized marital status |
| gender | NVARCHAR(50) | Customer gender sourced from CRM or ERP |
| birthdate | DATE | Customer date of birth |
| create_date | DATE | Customer creation date from CRM |

---

# gold.dim_products

## Purpose

Provides a consolidated product dimension enriched with category hierarchy and maintenance information. This table supports product analysis, category reporting, inventory insights, and sales performance analysis.

## Source Tables

- `silver.crm_prd_info`
- `silver.erp_px_cat_g1v2`

## Columns

| Column Name | Data Type | Description |
|------------|-----------|-------------|
| product_key | BIGINT | Surrogate key generated for each product |
| product_id | INT | Unique product identifier |
| product_number | NVARCHAR(50) | Product business key |
| product_name | NVARCHAR(50) | Product name |
| category_id | NVARCHAR(50) | Category identifier |
| category | NVARCHAR(50) | Product category |
| subcategory | NVARCHAR(50) | Product subcategory |
| maintenance | NVARCHAR(50) | Product maintenance classification |
| product_cost | INT | Product standard cost |
| product_line | NVARCHAR(50) | Product line classification |
| start_date | DATE | Product activation/start date |

# gold.fact_sales

## Purpose

Stores sales transaction data and links customers and products through surrogate keys. This fact table is the primary source for sales analytics, revenue reporting, customer purchasing behavior analysis, and product performance tracking.

## Source Tables

- `silver.crm_sales_details`
- `gold.dim_customers`
- `gold.dim_products`

## Grain

**One record per sales order line.**

## Columns

| Column Name | Data Type | Description |
|------------|-----------|-------------|
| order_number | NVARCHAR(50) | Unique sales order number |
| product_key | BIGINT | Foreign key to `gold.dim_products` |
| customer_key | BIGINT | Foreign key to `gold.dim_customers` |
| order_date | DATE | Date the order was placed |
| shipping_date | DATE | Date the order was shipped |
| due_date | DATE | Required delivery date |
| sales_amount | INT | Total sales value |
| quantity | INT | Quantity sold |
| price | INT | Unit selling price |

## Measures

| Measure | Formula | Description |
|----------|----------|-------------|
| Sales Amount | Quantity × Price | Revenue generated by the transaction |
| Total Quantity Sold | SUM(Quantity) | Total units sold |
| Average Selling Price | AVG(Price) | Average unit selling price |
